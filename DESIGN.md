# Design System: Idle Tower Defense Privacy Notice

**Project ID:** Local GitHub Pages site `yao624/idle-tower-defense-privacy`; local adaptation from the existing HTML/CSS and policy page. No Stitch project or API was used.

## 1. Visual Theme & Atmosphere

A quiet reading surface for a version-specific privacy notice. White paper and clear dark text keep the content easy to scan. The existing privacy blue links the page to the game's privacy screen. The scope, data practices and contact route lead the hierarchy; the page has no promotional hero, card grid, motion or decorative imagery.

## 2. Color Palette & Roles

- Paper white `#FFFFFF`: reading background and browser theme.
- Ink `#202124`: body text and headings.
- Secondary ink `#505B65`: update date and footer text.
- Privacy blue `#163F65`: underlined links and keyboard focus.
- Light privacy blue `#E3EDF7`: selection and focus emphasis.
- Divider gray `#CBD5DE`: title, scope and footer separators.

## 3. Typography Rules

System Segoe UI, Arial and generic sans-serif; no font download. Body text is 17px with 1.7 line height, reducing to 16px on narrow screens. Headings stay hierarchical and left aligned. Long package IDs and links can wrap.

## 4. Component Stylings

- **Links:** native underlined anchors with hover and visible `:focus-visible` states.
- **Navigation:** a labelled contents list linked to section headings, in document flow.
- **Containers:** flat text sections, separated only where scope and footer change context.
- **Forms and motion:** none.

## 5. Layout Principles

Desktop uses a 220px contents column beside a 73ch reading column. At 850px the columns stack; at 540px the contents list becomes one column and page gutters shrink to 20px. The document remains left aligned, respects safe areas, and includes a skip link and print layout.

## Verification scope

Review the real Russian and English copy at wide desktop, narrow desktop and mobile widths. Check keyboard focus, section anchors, long identifiers, zoom and horizontal overflow. This file records a local adaptation from the existing HTML/CSS; it does not claim a Stitch review.
